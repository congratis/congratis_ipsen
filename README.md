# Congratis

Интерактивная новогодняя ёлка с 20 шарами и персональными одноразовыми приглашениями.

## Stack

- Rust, Axum, Tokio
- RethinkDB 2.4.x через закреплённый Rust-драйвер reql = 0.11.2
- HTML/CSS/JavaScript
- Docker Compose
- Nginx 1.30.8 в отдельном контейнере, SSE через Changefeed

## Запуск

1. Скопируйте .env.example в .env.
2. Установите длинный случайный RETHINKDB_PASSWORD.
3. Создайте административный ключ командой openssl rand -hex 32 и запишите его в ADMIN_TOKEN в .env.
4. Запустите приложение и базу командой docker compose up -d --build.
5. Откройте сайт по адресу https://$DOMAIN, панель управления — https://$DOMAIN/admin/.

## Панель администратора

Панель /admin/ позволяет просматривать состояние всех 20 шаров, создавать приглашения пачкой и удалять неиспользованные приглашения. Для входа используется секрет ADMIN_TOKEN; API принимает его только в заголовке Authorization: Bearer. Ключ хранится в .env и не должен попадать в Git, переписку или ссылки.

Полная персональная ссылка показывается только в ответе на создание приглашения. Скопируйте её и сохраните сразу: в базе хранится только SHA-256 токена, восстановить исходную ссылку позднее нельзя. Использованные приглашения нельзя удалить из панели, чтобы случайно не потерять поздравления.

Если приглашение удалено, его номер шара становится свободным и может быть выдан повторно. Создание приглашений никогда не перезаписывает существующие записи.

## Архитектура

- Одна запись ornaments на шар; id равен номеру шара и защищает от повторного назначения номера.
- В БД хранится SHA-256 токена, исходный токен выводится только в персональной ссылке.
- Погашение приглашения — условный ReQL update одного документа; проверка used и запись поздравления выполняются атомарно.
- Удаление приглашения — атомарная условная замена: удалить можно только пока used=false.
- Отдельная сессия RethinkDB читает Changefeed; Axum публикует события через SSE.
- EventSource обновляет отдельный шар, а при подключении/переподключении загружает snapshot.
- Nginx обслуживает frontend, проксирует API и отключает buffering для SSE.

## Production

Для production-развёртывания используйте Ubuntu 26.04 LTS; установите Docker Engine скриптом deploy/scripts/install-docker-ubuntu.sh. Перед запуском укажите домен, настройте DNS и firewall, получите Let's Encrypt сертификат и завершите production smoke-test. Не публикуйте RethinkDB или порт приложения напрямую.

Не коммитьте .env или файл с приглашениями. Первый выпуск TLS: bash deploy/scripts/issue-certificate.sh. Автоматическое продление настраивается systemd unit/timer из deploy/systemd/.

Подробности — docs/ADR-RETHINKDB-REALTIME.md и docs/DEPLOYMENT.md.
